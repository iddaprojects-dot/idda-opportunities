# IDDA Opportunities – data

This repository holds the list of grants and youth opportunities shown on
https://idda-erasmus.com/opportunities/

- `data.json` – the list the website reads (updated every week)
- `UPDATE.md` – how the weekly update works
- `tools/validate.py` – checks the file before each update

IDDA shares this information from external sources for information only.
Always check the official website of each programme before applying.
